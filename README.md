# 奶宝碰碰乐

奶娃主题的合成小游戏，独立编写页面与圆形碰撞引擎，使用新的 OpenMoji 角色素材。

- 手机：拖动瞄准，松手投放。
- 电脑：移动鼠标瞄准，点击投放；点选游戏区域后也支持方向键与空格。
- 两个同级角色合成下一等级，共十级。
- 每 2000 分获得一枚复活币，两只最高级角色相遇奖励 500 分与一枚复活币。
- 排行榜保存到 Cloudflare D1，显示最近 100 局中的前 20 名，重复提交同一局不会重复入榜。
- 在排行榜的成绩旁点击“改名”，可直接修改已提交的昵称；结算页提交后也可再次修改昵称。
- 改名是当前私有网站的管理功能，依赖 Sites 的仅所有者访问权限并要求登录身份。若开放给其他玩家，应先增加每位玩家对成绩的归属校验。

## 本地开发

需要 Node.js 22.13 或更高版本及 npm。

```sh
npm run install:ci
npm run dev
npm run build
```

数据库表由 `db/schema.ts` 定义，迁移文件在 `drizzle/`。
上线时通过 Sites 绑定 D1 并应用迁移；本地排行榜也需要先应用本地数据库迁移。

## 素材与代码

角色来自 [OpenMoji](https://openmoji.org/)，遵循 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)，SVG 未修改。
完整出处见 `public/characters/ATTRIBUTION.md`。页面页脚也标明作者和授权。
游戏未复制参考网站的角色贴图、收款码、排行榜服务或页面代码。

网站包含服务端排行榜，不能直接作为纯静态 GitHub Pages 网站运行。
GitHub 仓库用于保存源代码，在线游戏由 Sites 托管。
排行榜接受客户端成绩，适合朋友之间娱乐，没有实现竞技级防作弊。
